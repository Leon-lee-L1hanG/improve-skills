# improve-skills · 技能审查与完善

用于 Codex 的技能优化工作流：审查现有 Skill 的真实需求、补问策略、执行边界、模板、脚本与交付验收，实际修改并进行适当验证。

## 安装

将本仓库放到个人技能目录中的 `improve-skills` 文件夹：

```sh
git clone https://github.com/Leon-lee-L1hanG/improve-skills.git ~/.codex/skills/improve-skills
```

若设置了 `CODEX_HOME`，则安装到其 `skills/improve-skills` 子目录。已存在同名技能时先检查本地修改，不直接覆盖。若当前会话未识别，重新打开会话后调用。

## 使用

```text
使用 $improve-skills 完善【技能名、路径或仓库链接】。
先检查真实需求和实现，再修改、验证并说明未实测范围。
```

也可以指定问题或范围：

- “这个技能总是在缺资料时反复问我，检查并修复。”
- “优化这几个技能，保留已有功能，按各自用途分别检查。”
- “只做评审，暂时不修改文件。”
- “完善这个仓库中的技能，并同步已安装的本地版本。”

## 工作方式

1. 定位目标与正确版本，保留未提交修改和个人偏好。
2. 从用户期望结果出发，检查触发范围、最少输入、关键补问及完成标准。
3. 修复能造成跑偏、返工或错误验收的问题，同时核对模板和实现。
4. 按改动选择结构校验、情境复核、脚本回归或业务实测，明确未验证项。
5. 按授权同步目标文件；公共发布采用明确文件清单，隔离私人资料。

## 范围与依赖

这是给 Codex 执行的工作流，不是独立运行的修复程序，也不保证任意技能一次满足全部需求。文件访问、测试和仓库操作需要当前环境提供对应能力。

可配合环境中的 `skill-creator` 进行格式校验；缺少该工具时须说明验证限制。优化技能本身不代表授权执行其业务动作，不自动发信、购买服务、删除用户资料或公开私人内容。用户只要求评审时不修改文件。

本技能已通过结构、引用和安装一致性校验；这些检查不代表所有领域的完整业务效果已实测。
